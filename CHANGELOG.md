# Изменения версии 2.0.0

- Добавлена регистрация и вход по email/паролю через Firebase Authentication.
- Добавлен сброс забытого пароля по email.
- Посылки сохраняются в Cloud Firestore в пользовательском разделе `users/{uid}/shipments`.
- Добавлена realtime-подписка на изменения облачных данных.
- Добавлен безопасный перенос старых записей из IndexedDB: документы с совпадающими ID в облаке не перезаписываются.
- Добавлены Firestore Security Rules, ограничивающие доступ UID текущего пользователя.
- Добавлен `.env.example`; `.env.local` исключён из Git.
- Версии Vite и React-плагина закреплены на совместимой связке, вместо `latest`.
